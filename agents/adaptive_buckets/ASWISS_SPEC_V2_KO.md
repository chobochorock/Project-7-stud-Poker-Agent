## 1. 지표

- exploitability(NashConv/2)를 평균 정책과 현재 정책으로 나눠 잰다. [사용자 §1]
- bucket 수. [사용자 §1]
- 한 그림에 세 선을 그린다. [사용자 §4, §13]
  - 선 세 개: infoset regret-sum, bucket regret-sum, 그 차이.
  - 측정 전용 정보집합 표로 계산하며, 학습에는 쓰지 않는다. 차이는 항상 0 이상이다.
  - 학습 표 기준의 bucket regret-sum은 점선으로 겹친다.
  - 분할 시점에 세로줄을 긋는다.
- 추상화 없는 MCCFR을 같은 반복 수의 기준선으로 겹친다("CFR 수렴 정도"). [사용자 §4]

**큰 게임**

## 2. 공통 규칙

**posterior의 시작 칸** = (행동할 플레이어, 합법 행동 집합). [사용자 §4]
- 본래 뜻은 "하위 트리 구조가 같게 대응되는 규칙"이다. 다른 게임에 적용할 때는 다시 정의한다.

**분할 시점은 둘 중 하나를 옵션으로 고른다.** [사용자 §8]
- 정적 일정: T_k = 1000·2^k.
- ε 규칙: Σ bucket 평균 후회 < ε.
  - bucket 평균 후회 = 누적 후회 / 그 bucket이 생긴 뒤의 방문 수. [사용자 §19]
  - ε는 상수로, 첫 epoch(1000 반복) 끝의 값으로 고정한다. [사용자 §12, 기본값 §16]
  - 방문 25번 미만인 bucket은 부모의 값을 쓴다. [사용자 §12]
  - 분할 뒤 최소 1000 반복이 지나야 판정한다. [기본값 §16]

**분할 기준: 양의 방향 이상치 검정** [사용자 §8, §13]
- 이상치: 어떤 행동 a에서 (r(I,a) − μ_a)/σ_a가 문턱을 넘는 정보집합이다.
- 그 값이 가장 큰 행동의 자식으로 보낸다. 이상치가 아니면 ∅다.
- 분할 이득 확인은 하지 않는다.
- 검정:
  - 기본은 generalized ESD다. 옵션은 z·σ다.
  - ESD 설정 [기본값 §16]:
    - r = ⌊n/2⌋, α = 0.05/|A|, 단측
    - 문턱은 정규분포 모의실험으로 정확히 계산하고 n ≥ 5부터 쓴다. n ≥ 25 규칙은 옵션이다.
    - bucket마다 표본 정보집합 64개
- 척도: 기본은 반사실 후회 r(I,a)다. 옵션은 `fact-counterfact`다(올 때마다의 값으로 이상치를 찾고, 반사실 척도로 가치를 확인). [사용자 §8]

**분할 뒤 자식 표** [사용자 §8]
- 기본은 재시작이다.
- 옵션은 약한 상속이다: 후회 λ·부모, 평균 표 μ·부모.

**방향 계산** [사용자 §12, 기본값 §16]
- 작은 게임: 순간 전략 합이다. K_k = 8(k+1)로 상한 없이 키운다(K = ∞와 같은 보장).
- 큰 게임: 분할 시점 평균 전략의 후회다.
- 상수 K는 옵션이다.

**표 사용** [사용자 §4]
- 할당 표(라우팅 캐시)는 표 없이 계산한 결과와 같다는 보증(동일성 시험) 아래에서만 가속용으로 쓴다.

## 4. prior–posterior

**구조** [사용자 §1]
- 전략은 posterior bucket에만 있다.
- prior 칸은 posterior bucket을 가리키는 포인터만 가진다.

**prior의 시작은 두 옵션이다.** [사용자 §8, §13]
- `equal abstraction`: posterior와 같은 칸, (플레이어, 합법 행동 집합).
- `length abstraction`: (플레이어, 합법 행동 집합, 관측 길이). 관측 길이 = 받은 관측의 수, stud에서는 스트리트.

**prior 특징** [사용자 §5, §19]
- 정보집합이 담은 모든 정보다: 카드와 베팅 이력.
- 분할 직전에만 완전 부호화로 표본을 나타내고, 쓸모 있는 성분을 고른다.
- 학습 중에는 고른 성분만 계산한다.
- power 특징(k-means atlas의 입력)은 쓰지 않는다.

**prior 분할** [사용자 §4, §5, §12, 기본값 §16]
- 결정 트리로 나눈다: 특징 하나의 문턱으로 이진 분할한다.
- 라벨은 regret 벡터이고, 거리는 도달확률 가중 유클리드다. TARA 트리 하나의 기준과 같다.
- 교차 추정을 쓴다.
- 계기: 가리키는 prior 칸이 없는 posterior 자식 (가), 또는 한 칸의 표본 라벨이 갈림 (나).
  - (나)는 "m개 표본의 라벨이 두 가지 이상"이다.
- 잎 수 상한은 전체 합이다. prior 분할 사건마다 현재 잎 수의 2배로 올리고, 신호가 난 칸만 나눈다.
- posterior에는 잎 수 제한이 없다.

**할당** [사용자 §4, §8, §12, §15]
- 포인터는 m번 방문(m = 16)의 방향 합으로 정한다. 첫 표본 하나로 정하는 것은 옵션이다.
- 학습하면서 할당한다.
  - m번이 차기 전에는 방문한 정보집합을 posterior 계보로 직접 돌린다.
  - 그 방향은 m개 표본의 하나로 쓴다.
- 옵션: 학습을 멈추고 최대 N·2^i개 노드만 탐색하는 기간.
- 할당 계산은 CPU 시간에만 센다. 반복 수에는 세지 않는다.
- 분할된 prior 칸은 모두 다시 정하고, 분할되지 않은 칸은 유지한다.
- 새 prior 잎은 (α) 계보 라우팅으로 정한다.
  - 처음 분할부터 posterior 분할 사건을 따라 내려가며, m개 표본 방향 합의 라벨로 자식을 고른다.
  - 옛 단계의 bucket은 지금 bucket의 계보상 조상이다.
- posterior 분할은 정보집합 표본(방문)으로 판정하고, 할당은 prior 칸 단위로 한다. [기본값 §16]

## 5. 이론 전개 순서 [사용자 §10, §12, §15]

1. 먼저 "prior와 posterior 사이의 거리가 조건 이하이면 prior–posterior abstraction은 수렴한다"를 세운다.
   - 거리는 prior 트리의 깊이(순회거리)다.
   - 깊이와 regret 차이의 관계는 사용자가 이론을 개발해 온다. 2^{−d} 꼴은 가정하지 않는다.
2. 그다음, 세부 구성이 그 조건을 만족하는 구조임을 보인다.
3. 깊이별 칸 안 regret 차이를 재는 측정 도구를 넣어 둔다. 사용자의 이론 개발용이다. [기본값 §16]
