# AE / VQ-VAE abstraction 파일럿: 2026-09-23

## 요약

사용자가 지정한 low-fold 정책으로 C++ 7-stud 데이터를 새로 만들고 AE+k-means,
VQ-VAE, 원본 feature+k-means, random encoder+k-means를 비교했다.
**같은 256개 카드 코드에서 원본 power feature의 압축 오차는 k-means가 가장 작았다.**
AE/VQ가 전략적으로 약하다는 결론은 아니다. 이번에는 CFR 학습이나 LBR 평가를 하지 않았다.

## 조건

- 프로젝트 C++ 7-stud v3, heads-up, ante 1000칩, stack 1000 antes.
  기존 fixed heuristic H4 discard/reveal 유지. 5~7구의 기존 raise cap 1/2/3.
- 새 trajectory 10,000핸드, 수집 seed 20260923, 행동 이전 관측 81,513개.
  MCCFR traversal 10,000회라는 뜻이 아니다.
- 핸드 단위 train/validation/test = 8,000/1,000/1,000. 양 좌석/모든 구의
  관측이 같은 split에 속한다. Fold 외 행동은 그 시점의 합법 행동 내에서 균등하다.
- 기존 hard-256과 같은 18D power 입력, completion sample limit 128,
  구별 256개 카드 코드. 실제 전략 bucket에는 actor/합법 행동/베팅 문맥도 필요하다.
- 과거 epsilon-0.2 self-play atlas를 그대로 비교하지 않고 이번 데이터로 baseline도 재학습.
- Seed 11/22/33. AE/VQ 각 구별 2000회 update, batch 256, hidden 64, latent 8.
  첫 200회는 연속 AE warmup, VQ는 train embedding k-means로 codebook 초기화.
  Seed별 encoder/decoder 초기값과 minibatch 순서는 동일하다.
- Validation 복원 오차로 checkpoint 선택. 보상/전략/regret label은 모델 fitting에 사용하지 않음.
  코드 및 정확한 실행법: [README](README.md).

| 구 | 설정 fold 확률/decision | 실제 관측 비율 | decision 수 |
|---|---:|---:|---:|
| 5 | 2.625% | 2.5183% | 26,804 |
| 6 | 6.125% | 6.1850% | 29,733 |
| 7 | 8.750% | 8.9366% | 24,976 |

차이는 난수 표본 변동이다. 전체 765개 street/legal-mask 조합에 대한 확률합,
불법 행동 확률 0, fold 확률, 나머지 행동의 균등성 자체는 C++ 테스트로 확인했다.

## 압축 진단

각 코드에 속한 TRAIN power vector의 평균을 복원값으로 삼고 TEST MSE를 측정했다.
모든 방법에 같은 진단용 복원 규칙을 적용했다. 이 지표는 Euclidean k-means의 학습
목적과 직접 맞닿아 있으므로 전략적 지표로 일반화하지 않는다. 아래는 3 seed 평균이다.

| 방법 | 5구 MSE | 6구 MSE | 7구 MSE |
|---|---:|---:|---:|
| 원본 k-means | **0.002827** | **0.002550** | **0.002195** |
| Random encoder+k-means | 0.004727 | 0.004178 | 0.003475 |
| AE+k-means | 0.003114 | 0.002820 | 0.002471 |
| VQ-VAE | 0.003129 | 0.003052 | 0.002888 |

AE는 random encoder보다 개선되었지만 원본 k-means보다 압축 오차가 컸다.
VQ-VAE가 실제로 사용한 train code 수는 5구 249~256, 6구 232~252,
7구 191~235였다. 전체 collapse는 아니지만 7구에서 일부 code가 사용되지 않았다.

## 수익 예측과 해석 제한

이 수익 예측은 actor/legal-mask/code별 TRAIN 평균 수익을 TEST에 적용하는 보조 probe다.
핸드/actor/구별 첫 decision 하나만 사용하며, 새로운 bucket은 actor/legal-mask 평균으로
대체한다. 관측 수익은 이번 랜덤 정책의 결과이지 CFV, 최적 Q, regret가 아니다.

| 방법 | 5구 RMSE, ante | 6구 | 7구 |
|---|---:|---:|---:|
| Actor/legal-mask 평균만 | **90.85** | **95.05** | **105.50** |
| 원본 k-means | 93.00 | 98.33 | 109.30 |
| AE+k-means | 92.97 | 98.86 | 108.00 |
| VQ-VAE | 93.90 | 97.92 | 108.60 |

이 데이터/단순 평균 probe에서는 bucket을 더 세분한 이점조차 확인하지 못했다.
Bucket별 표본 부족과 수익 잡음의 영향이 가능하지만 원인을 분리한 추가 실험은 없다.
작은 RMSE 차이를 CFR의 강함/약함으로 해석하지 않는다. Seed SD는 같은 데이터에
대한 학습 변동이며 독립 test 신뢰구간이 아니다.

## 저장과 검증

- 주 실험 결과: [data/power_lowfold_10k_20260923](data/power_lowfold_10k_20260923/).
  압축 데이터 약 2.01MiB, 36개 모델/지표/그래프 포함 약 3.08MiB.
- AE/VQ checkpoint는 모델당 약 25.3KiB이며 구/seed별로 분리했다.
  모든 checkpoint의 재로딩 후 bucket ID 일치를 검사했다.
- Python 테스트 7개(기존 CPC 검사 포함)와 C++ collector self-test 통과.
  카드 비공개 정보 불변성, 입력에서 action/outcome 제외, history overflow 거절,
  VQ encoder/decoder/codebook gradient, 합법 행동집합 구분을 포함한다.
- 학습은 CPU. 보고된 RSS 증가량은 같은 프로세스의 allocator/초기화 영향을 받는다.
  AE 104.6MiB와 VQ 13.8MiB 최대 증가량을 모델 고유 메모리 차이로 해석하지 않는다.
- `--scope infoset`은 1832D 전체 observer 입력으로 구현하고 100핸드/30-update,
  8-code smoke를 통과했다. 이 작은 작동 검사를 성능 실험으로 보고하지 않는다.
  전체 history 입력 또는 원본 보관만으로 압축 후 perfect recall을 보장하지 않는다.
- 다음 전략적 검증에는 frozen encoder의 C++ 추론 연결 및 동일 예산 MCCFR/LBR이
  필요하다. 이번 결과에 그러한 solver 학습이 포함되었다고 주장하지 않는다.
