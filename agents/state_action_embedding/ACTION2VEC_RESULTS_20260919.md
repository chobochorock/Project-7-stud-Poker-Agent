# Chance-aware action2vec 실험 결과 (2026-09-19)

## 결론

**상대 행동 예측은 학습됐지만, 최종 보상을 잘 예측한다는 근거는 얻지 못했다.**
Chance를 입력에 남기고 직접 예측 대상에서만 제외하는 구조는 동작한다.
그러나 이번 데이터와 학습 예산에서 보상 예측은 거의 0칩을 답하는 수준이다.
이는 이 구조의 불가능성 증명이 아니라 작은 파일럿의 부정적인 결과다.

## 조건

| 항목 | 실제 실행값 |
|---|---|
| 환경 | 기존 seven-poker v3, 2인 cash, 초기 1000칩, ante 1; 표준 카지노 Stud와는 다름 |
| 데이터 | 9000핸드: random/random, heuristic/heuristic, mixed 각 3000 |
| 분할 | 학습 7200 / 검증 900 / 테스트 900핸드; 양쪽 관점은 같은 분할 |
| 수집 seed | 20260919 |
| 모델 seed | 11, 22, 33; 세 방식에 동일하게 적용 |
| 사건 입력 | 종류, 상대적 주체, 카드, 행동, street, 실제 지불 칩 |
| 문맥 | 평균 35.90, 최대 57사건; 전체 prefix, 잘라내기 없음 |
| 모델 | 64차원, 2층 causal Transformer, 4 heads, 총 88,829 parameters |
| 사전학습 | 800 updates, batch 32, Adam 0.0005; none은 생략 |
| 보상 학습 | 모든 방식 1200 updates, batch 32, Adam 0.0003 |
| 선택 기준 | 사전학습은 검증 상대-action NLL, 보상 모델은 검증 RMSE |
| 테스트 | 900핸드의 1800관점; 독립 표본 1800개로 취급하지 않음 |
| 실행 | CPU, PyTorch 2.13.0+cpu, 4 threads; GPU 미사용 |

각 핸드에서 베팅 결정 하나를 골라 **그 행동이 실행되기 전** 사건열로 최종 순수익을
예측했다. 현재 실제 행동, 이후 카드·행동, 최종 정산, 상대 비공개 카드는 입력에서 제외했다.
게임 종료 후 한 번 나온 수익을 label로 썼으며, 동일 prefix의 반복 rollout 평균은 아니다.

상대 행동 예측은 intervening chance가 이미 관측된 이후의 다음 상대 베팅 행동에 대한
예측이다. 미래 카드를 보기 전에 상대 반응을 예측했다는 의미는 아니다.

`players`는 상대 BET에만 CE를 준다. `all`은 이에 보이는 DEAL 카드의 CE를 추가한다.
자기 행동, discard/reveal 선택, 자동 경계, 상대의 숨겨진 카드까지 모두 예측하는 LM은 아니다.
두 loss의 전체 target 수로 평균하므로 동일 update 수여도 상대-action loss의 비중은 다르다.
기존 heuristic은 데이터 생성에 사용했다. heuristic-free 실험이라고 부르지 않는다.

## 보상 예측

세 seed의 테스트 평균. 괄호 안은 seed 표준편차이며 신뢰구간이 아니다.

| 방식 | RMSE, 칩 (낮을수록 좋음) | MAE, 칩 | R² |
|---|---:|---:|---:|
| 학습 평균 0칩 고정 | 78.704 | 14.938 | 0.000000 |
| 현재 관측 raw vector + ridge | 80.753 | 21.305 | -0.052739 |
| none: 사전학습 없이 보상만 학습 | 78.700 (0.006) | 14.956 | 0.000101 |
| players: 상대 행동 전용 사전학습 후 보상 학습 | 78.753 (0.025) | 15.187 | -0.001249 |
| all: 상대 행동+chance 사전학습 후 보상 학습 | 78.717 (0.045) | 15.034 | -0.000330 |

R²=0은 테스트 평균을 답하는 것과 같은 오차다. 음수는 그보다 나쁜 수치다.
전체를 fine-tuning하지 않고 표현을 동결한 ridge probe의 RMSE도 none 78.661,
players 78.759, all 78.723으로 의미 있는 보상 표현 개선을 보여주지 않았다.
Raw ridge가 나빴다는 사실만으로 action2vec이 유용하다고 결론내릴 수 없다.

양쪽 관점을 묶은 900핸드 단위 paired bootstrap, 2000회:

| RMSE 차이: players에서 비교군을 뺌 | 차이, 칩 | 조건부 95% 구간 |
|---|---:|---:|
| players - none | +0.053 | [-0.201, +0.349] |
| players - all | +0.036 | [-0.105, +0.193] |
| players - 고정 0칩 | +0.049 | [-0.213, +0.354] |
| players - raw ridge | -2.000 | [-5.463, +0.164] |

음수여야 players에 유리하다. 모두 0을 포함하므로 우월성을 주장하지 않는다.
Seed별 squared error를 평균한 후 핸드를 재표본추출했다. 예측값을 평균한 ensemble
성능이 아니다. 이 구간은 고정된 모델과 데이터에 조건부이며 학습 seed 불확실성 전체를
포함하는 구간은 아니다.

## 상대 행동 예측

보상 fine-tuning 전 checkpoint를 평가했다. NLL은 낮을수록, 정확도는 높을수록 좋다.
학습·평가 양쪽에서 환경의 현재 legal-action mask를 사용했다.

| 방식 | 전체 NLL | 정확도 |
|---|---:|---:|
| 합법 행동 균등확률 | 1.659 | 별도 집계 안 함 |
| 학습 데이터 행동 빈도 + 합법 행동 정규화 | 1.448 | 48.91% |
| players | 1.242 (0.004) | 53.05% |
| all | 1.266 (0.004) | 53.05% |

Players의 NLL은 heuristic/heuristic에서 0.815, mixed에서 1.329였다.
Random/random에서는 1.782로 균등확률 기준 1.592보다 나빴다. 혼합 데이터로 학습한
모델이 모든 상대에게 개선된 것은 아니다. 테스트는 알려진 정책의 새로운 핸드이며,
보지 못한 상대 정책에 대한 일반화나 private-hand belief 복원 능력을 검증한 것은 아니다.
행동 예측의 개선과 보상 예측의 개선은 구분해야 한다.

## 오차 진단과 한계

테스트 절대 수익의 중앙값은 3칩, 95% 분위수는 36칩, 최대는 1000칩이었다.
가장 큰 1%인 9핸드가 고정 0칩 예측의 제곱오차 **90.29%**를 차지했다.
학습·검증에서도 각각 89.16%, 85.41%였다. 드문 큰 결과가 MSE를 크게 좌우한다.
검증과 테스트의 0칩 RMSE부터 58.813과 78.704로 상당히 달랐다.

보상 예측 산점도에서 players/all의 예측값은 대부분 0 근처에 몰리고, 큰 승패를
구분하지 못한다. None의 seed 11과 33은 검증으로 step 0의 상수 모델이 선택됐다.
MAE에서도 개선이 없으므로 단지 RMSE라는 지표만의 문제로 취급하지 않는다.

가능한 설명은 학습 데이터·예산 부족, 희귀 대형 결과, 행동 모방 목적과 보상 목적의
차이, 카드 조합의 비선형성 등이다. 이번 실험은 원인별 분리 실험이 아니므로
어느 하나를 확정적인 원인이라고 말하지 않는다. 특히 행동 예측의 이득이 순서·장기
문맥 덕분인지는 last-event/순서 없는 요약과의 추가 비교가 필요하다.

다음 실험에서는 새로운 테스트 세트를 먼저 고정한 뒤 데이터·학습량을 늘리는 비교와,
같은 관측 prefix에 대해 **정보집합에 일관된 숨은 카드와 후속 정책**을 샘플링한
반복 rollout 평균 수익 label을 비교할 수 있다. 실제 숨은 상태 하나를 고정한 평균을
부분관측의 정답 EV로 간주하면 안 된다. Huber/분포 예측을 시험하더라도 평가의 칩
RMSE는 유지해야 하며, clipping으로 목표 자체를 바꾼 결과와 혼동하지 않는다.
이 후속 실험들은 아직 실행하지 않았다.

## 자원과 검증

- Players: 사전학습 평균 14.36초 / 보상 학습 19.72초; 각 phase 검증 시간 포함.
- All: 14.66초 / 19.50초. None의 보상 학습은 18.46초.
- 각 학습 phase의 sampled peak RSS 평균은 약 376~381 MiB. 실행 전체의 최고 메모리나 GPU VRAM 측정은 아님.
- 데이터 압축 크기 1,517,708 bytes. 전처리 배열은 38,466,000 bytes.
- 기존·신규 unit test 총 7개 통과. 모든 9개 value checkpoint 재로드 후 예측 일치 확인.
- 생성 중 각 선택 prefix의 관측 카드/스택 복원, chip conservation 확인.
- 보고서 생성 시 핸드 단위 분할, 두 관점 zero-sum, 상대 private-card 차단 확인.
- 미래 사건 변경에 대한 causal 불변성, 직접 chance-head gradient 차단과 chance embedding gradient 유지 검사 통과.

실험 산출물은 `data/action2vec_20260919/`에 있다. `pretrained.pt`, `value.pt`는
추론용이며 optimizer/RNG를 포함한 학습 재개 checkpoint가 아니다.
별도의 `data/action2vec_smoke_20260919/`는 구현 점검용으로 본 결과에 포함하지 않는다.
기존 Skip-gram/CPC 파일럿 및 게임 규칙은 변경하지 않았다.
