# CPC 파일럿 검토: 2026-09-23

## 결론

기존 파일럿에서 뚜렷한 미래 정보 누출이나 causal mask 오류를 확인한 것은 아니다.
그러나 **미래 후보 구분 과제가 카드 정체성만으로 풀리는 심각한 평가 한계**가 있다.
기존 목적함수·후보 구성 그대로 학습량만 늘리는 재실험은 권하지 않는다.
미래의 새로운 정보와 history의 기여를 분리하는 과제로 바꾸면 재실험할 가치는 있다.

## 실제 확인한 것

- 기존 테스트 3개 재실행 통과: 비공개 정보 불변성, causal/padding 불변성,
  encoder gradient 및 체크포인트 재로딩. 테스트의 범위를 넘어 무오류를 증명하지 않는다.
- 기존 데이터: Python 세븐포커 v3, uniform 합법 행동, random discard/reveal,
  6,000핸드, 데이터 seed 20260919. 이번 AE/VQ의 C++ fixed-H4 환경과 다르다.
- 기존 encoder 입력은 현재 관측과 **이미 선택된 행동**이다. 이것을 수정 없이
  행동 이전 정보집합 bucket에 사용하는 것은 입력 시점이 맞지 않는다.
- CPC는 243D local encoder와 2층 causal Transformer를 사용한다. local encoder
  평가와 문맥 출력 평가가 구분되어 있었고, 문맥 출력도 기존 probe에서 개선되지 않았다.
- 핸드 단위 split과 같은 핸드 negative 제외는 코드상 적용되어 있다. 다만 다른
  핸드의 무작위 후보는 카드 조합만으로 구분하기 쉬우므로 이것만으로 충분하지 않다.
- 코드 경로: `experiment.py`의 `encode_event`, `pair_groups`, `contrastive_loss`,
  `frozen_features`, `linear_probe`. 기존 구현/체크포인트를 수정하지 않았다.

## 추가 진단 결과

동일한 test split에서 seed 9123으로 64개 후보 x 60개 batch를 고정했다.
1/2 betting-action horizon 및 미래 street별 후보 구성, 같은 핸드 false-negative
제외 방식은 기존 평가와 동일하다. CPC seed 11/22/33 모두 다시 불러왔다.

| 진단 | 미래 후보 retrieval 정확도 |
|---|---:|
| 학습 없이 현재 카드와 후보 카드 multi-hot cosine 비교 | **100%** |
| 학습 없이 카드 이외 현재 feature cosine 비교 | 1.068% |
| CPC 전체 prefix | **100%**, 3 seed 모두 |
| CPC 과거 토큰을 0으로 대체, 현재 위치 유지 | **100%**, 3 seed 모두 |
| CPC 과거 토큰 순서 shuffle | **100%**, 3 seed 모두 |

원시 카드 겹침만으로도 만점을 얻었다는 것은 모델이 무엇을 학습했는지와 무관하게
이 retrieval 지표가 전략 표현을 식별하기에 불충분함을 보여준다. history 개입은
분포 밖 입력이므로 모델 내부 원인을 확정하는 인과 실험으로 해석하지 않는다.
무작위 미래 카드를 정확히 생성/예측한 결과도 아니다.

기존 frozen probe 수익 RMSE: raw 88.207, random encoder 90.337,
CPC local 90.594, CPC context 91.140칩. 이 짧은 800-update 파일럿에서 CPC의
이점을 확인하지 못했다. Random 상대의 행동은 private hand에 반응하지 않으므로,
상대 범위 추론을 배웠는지 평가하기에도 부족한 데이터였다.

## 재실험한다면 바꿀 것: 제안, 아직 미실행

1. 이번 지정 fold 정책과 C++ 5~7구 범위에 맞추고 행동 이전 observer input으로 통일한다.
2. 카드 정체성이 겹치는 것만으로는 해결되지 않도록 공개 카드/구/합법 행동 조건을
   맞춘 후보 또는 미래의 새 정보 예측 과제를 설계한다. 단순히 더 많은 랜덤 negative를
   추가하는 것은 해결책이 아니다. False negative 및 관측상 구별 불가능한 후보도 주의한다.
3. Chance의 실현값을 맞히기보다 가능한 미래 관측의 조건부 분포를 평가하고,
   현재 관측만 쓰는 모델과 history 모델을 같은 target/후보/예산에서 비교한다.
4. 지정 low-fold 정책 역시 패와 무관한 행동이다. History를 통한 전략 추론을 확인하려면
   다른 패 의존 정책 데이터가 별도로 필요하지만, 이번 사용자 지정 조건에 섞지 않는다.
5. 단순 카드 겹침, random encoder, no-history 모델을 계속 대조군으로 둔다.
   최종적으로 frozen bucket의 CFR/LBR 성능을 측정해야 하며 retrieval를 대신 쓰지 않는다.
