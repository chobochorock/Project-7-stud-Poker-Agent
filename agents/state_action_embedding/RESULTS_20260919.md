# 7-Stud 상태·행동 embedding 파일럿: 2026-09-19

## 결론

**이번 실험에서는 CPC 사전학습의 우위를 확인하지 못했다.** 두 모델 모두 미래
embedding 구분 과제를 쉽게 풀었지만, 공통 수익 예측에서는 사전학습하지 않은
encoder보다 나아지지 않았다. 이는 CPC 일반에 대한 반증이 아니라, 이 데이터와
목적함수에서 대조학습 과제가 전략적 표현의 벤치로 불충분하다는 관측이다.

## 정확히 비교한 것

- 기존 Python 세븐포커 v3, heads-up cash, 1,000칩/ante 1. 표준 카지노 Stud 아님.
- 랜덤 합법 행동 및 랜덤 discard/reveal로 6,000핸드. 공유 수집 seed 20260919.
- train 4,800 / validation 600 / test 600핸드. 동일 핸드의 두 시점 관점은 같은 split.
- 두 관점의 betting event 합계 49,282개. 평균 길이 4.107, 최대 길이 15.
- 공통 local encoder: 관측·행동 243차원 -> MLP -> 64차원. history 입력 없음.
- Forward Skip-gram: 현재 embedding으로 1·2개 betting event 뒤 embedding 구분.
- CPC: 같은 encoder + causal Transformer 2층, 4 heads, 64차원, 문맥 상한 16.
- 원래 word2vec의 양방향 주변 window가 아니라 **같은 미래 pair를 쓰는 대조군**.
- 같은 초기 encoder seed 11/22/33, batch 64, Adam lr 0.001, 800 update.
- CPC는 문맥과 추가 parameter를 쓰므로 equal FLOPs/동일 파라미터 비교는 아니다.
- 설치된 PyTorch 2.13.0+cpu, FP32, CPU threads 4. GPU 실험은 하지 않았다.

## 공통 벤치

encoder를 고정하고, 같은 선형 예측기로 다음 행동과 실제 최종 칩 수익을 예측했다.
각 player/hand에서 다음 행동이 존재하는 기준점 하나만 선택했다. 따라서 test는
600개 중 적합한 499핸드, 두 관점 합계 998개이다. 최종 fold 등으로 이미 정산이
확정된 마지막 사건은 기준점에서 제외한다. 검증 손실로 probe checkpoint를 선택하고
test는 선택에 사용하지 않았다. 세부사항과 실행법은 [README](README.md).

| 표현 | 수익 RMSE, 칩 ↓ | 다음 행동 NLL ↓ | 다음 행동 정확도 ↑ |
|---|---:|---:|---:|
| 평균 수익 / 행동 빈도 상수 | 90.408 | 1.7167 | 44.89% |
| 원본 현재 feature | 88.207 | 1.6131 | 41.28% |
| 학습하지 않은 random encoder | 90.337 ± 0.099 | 1.6286 ± 0.0118 | 43.82% |
| Skip-gram local encoder | 90.721 ± 0.225 | 1.6287 ± 0.0111 | 44.76% |
| CPC local encoder | 90.594 ± 0.108 | 1.6716 ± 0.0056 | 44.82% |
| Skip-gram history 평균 | 90.698 | 1.6877 | 44.89% |
| CPC history 평균 | 90.708 | 1.7105 | 44.89% |
| CPC Transformer 문맥 출력 | 91.140 | 1.6949 | 44.86% |

±는 같은 데이터에 대한 3개 학습 seed의 표준편차이며, 신뢰구간이 아니다.
두 플레이어 관점도 독립 표본이 아니다. 원본 feature baseline은 입력 차원이 더
크므로 parameter-matched 비교는 아니며, 정보 손실 여부를 보는 참조점이다.
CPC 문맥 출력과 현재 encoder 출력도 입력 정보량이 다르므로 분리해서 해석한다.

NLL과 정확도 순위가 다른 것은 모순이 아니다. NLL은 실제로 나온 행동에 부여한
확률을 평가하고 정확도는 최고 확률 행동의 일치만 본다. 빈도가 높은 행동만
선택해도 약 45% 정확도가 나오므로 여기서는 정확도보다 NLL이 더 유용하다.

## 다음 embedding 정확도가 왜 불충분한가

저장한 6개 checkpoint를 다시 로드해서, test split에서 60 batch × 64개 기준점으로
측정했다. 같은 미래 street의 다른 핸드 후보를 사용하고 같은 핸드는 negative에서
제외했다. 학습 때와 별도의 고정 audit sampling seed를 사용했다.

- 모든 모델의 미래 embedding retrieval 정확도: **100%**.
- CPC도 과거 문맥을 버리고 마지막 사건 하나만 입력한 경우: **100%**.
- 이 결과는 정해진 후보들 중 실제 미래를 골랐다는 뜻이며, 무작위 미래 카드를
  100% 예측했다는 뜻이 아니다.

이 과제는 현재 사건만으로도 해결된다. 같은 핸드의 카드들이 다음 사건에도 유지되는
특징을 이용했을 가능성이 크다. 카드 제거 등 별도 ablation 없이 원인을 단정할 수는
없다. CPC의 문맥 절단은 positional input도 바꾸는 진단 실험이다.
**retrieval 100%는 전략 이해나 좋은 Q 근사를 입증하지 않는다.**

## 메모리

모든 값은 MiB(2^20 bytes). 합성 dense 입력, FP32, batch 64, 각각 새 프로세스에서
horizon-1 학습 10 step의 working set을 10 ms 간격으로 측정했다. 모델·optimizer뿐
아니라 Python/PyTorch와 지연 초기화 비용도 포함한다. 순간 peak를 놓칠 수 있다.

| 항목 | Skip-gram | CPC |
|---|---:|---:|
| 학습 모델 전체 parameter | 47,808 | 115,776 (문맥 16) |
| 전체 parameter FP32 저장량 | 0.182 | 0.442 |
| local encoder parameter | 39,616 | 39,616 |
| local encoder FP32 저장량 | 0.151 | 0.151 |
| 문맥 8: 프로세스 RAM peak | 271.37 | 279.98 |
| 문맥 16: 프로세스 RAM peak | 271.88 | 286.63 |
| 문맥 32: 프로세스 RAM peak | 272.39 | 304.00 |
| 문맥 64: 프로세스 RAM peak | 274.29 | 329.64 |
| 문맥 16: import baseline 대비 증가 | 77.22 | 92.49 |
| 문맥 64: import baseline 대비 증가 | 79.81 | 134.58 |

Skip-gram도 공통 입력 버퍼 B×L을 받아 마지막 사건만 처리하므로 입력 버퍼만큼은
L에 따라 증가한다. CPC에서는 attention/중간 activation 비용까지 늘어난다.
학습 후 Transformer와 예측 head를 제거하면 두 방식 모두 같은 크기의 local
encoder만 남는다. 64차원 FP32 embedding 하나의 payload는 256 bytes로 동일하다.

실제 데이터 학습에서는 호스트에 padded dataset을 로드한 뒤 RAM baseline을 잡았다.
Skip-gram의 학습 중 추가 RAM은 8.79~9.70 MiB, CPC는 25.36~25.84 MiB였다.
실제 최대 sequence 길이가 15이고 batch마다 padding 길이가 달라 합성 실험과 다르다.
800회 사전학습 루프 시간은 Skip-gram 1.73~2.24초, CPC 7.10~7.17초였다.
데이터 생성·probe 학습·저장·평가 시간은 이 시간에 포함하지 않았다.

별도 batch 1 추론에서는 전체 모델을 메모리에 유지한 상태로 측정했다.
local encoder만 실행할 때 import 대비 RAM 증가는 Skip-gram 2.13 / CPC 2.81 MiB,
문맥 경로 실행은 2.42 / 4.64 MiB였다. 이는 총 tensor 메모리의 정밀 측정은 아니다.

**GPU 메모리는 미측정이다.** 설치된 CPU PyTorch로 얻은 RAM 수치를 GPU 요구량으로
환산하지 않는다. 코드에는 CUDA allocated/reserved peak 기록 경로가 포함되어 있다.

## 다음 실험의 기준

1. 현재 retrieval는 너무 쉬우므로 주 지표에서 제외하고 진단 지표로만 유지한다.
2. 공통 외부 target의 NLL/RMSE로 정보 보존을 보고, random encoder를 반드시 둔다.
3. 최종 목적은 동일 RL 예산의 학습 속도와 미학습 상대에 대한 칩 수익이다.
   동일 deal/seat 교차 및 핸드 단위 불확실성 추정이 필요하다. 아직 실행하지 않았다.
4. 균일 랜덤 상대에는 패에 따라 베팅하는 정보가 없다. 상대 범위·블러핑을 배우는
   실험은 패에 따라 행동하는 상대 또는 self-play snapshot을 포함해야 한다.
5. 현재 결과에서 CPC가 일반적으로 나쁘다거나 평형에 수렴하지 못한다고 결론낼 수
   없다. 이 실험은 exploitability, CFR regret, 최적 Q를 측정하지 않았다.
